# Ücretsiz / açık kaynak Godot oyunları — MegaGames aday listesi

Hedef: 2D ve 3D için 50'şer aday. Bu dosya yalnızca aday listesidir; hiçbir şey indirilmedi.

Lisans sütunu: "belirtilmedi" ise kaynakta açık bir lisans bulunamadı; indirmeden önce proje sayfasındaki LICENSE dosyası kontrol edilmeli.

## Kaynaklar

- awesome-godot (godotengine GitHub deposu): https://github.com/godotengine/awesome-godot
- Resmi godot-demo-projects (MIT): https://github.com/godotengine/godot-demo-projects
- itch.io "Open 3D games made with Godot" koleksiyonu: https://itch.io/c/566504/open-3d-games-made-with-godot
- Godot Asset Library (MIT olarak listelenen 3D projeler): https://godotengine.org/asset-library/asset
